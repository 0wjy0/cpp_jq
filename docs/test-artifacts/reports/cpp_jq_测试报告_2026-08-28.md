## 6. 关键观察

### 6.1 字节级 parity 验证(tojson ≡ tostring)

对 4 种代表性输入(string/number/array/object)分别用 `tojson` 和 `tostring` 调用,stdout 字节级一致。这印证了 spec §2 的关键架构事实:

- `nlohmann::json::dump()` + cpp_jq 当前 printer(总是 dump) = tojson 与 tostring 等价
- 委托实现不存在信息损失或行为偏差

### 6.2 nlohmann::json key 排序行为

TC-09 中输入是 `{"name":"Bob","age":7,...}`,实际输出 key 顺序是 `age,name,off,on,tags`(字典序)。这是 `nlohmann::json` 的标准行为,与 jq 保留插入顺序不同。这是 cpp_jq 的预期行为,不影响功能正确性,已在 spec 表格 4.1 中隐含说明。

### 6.3 CLI 调用路径

- `tojson` 独立可用:`echo '...' | cpp_jq 'tojson'` ✓
- `tojson` 配合 pipe:`.b|tojson` ✓(TC-10)
- `tojson` 配合 identity pipe:`.|tojson` ✓(TC-11)
- NDJSON 多行输入:每个值独立处理 ✓(TC-12)
